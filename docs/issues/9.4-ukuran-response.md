## Ringkasan
Query memakai `SELECT *` sehingga `request_base64_ktp`, `profile_pic`, dan `selfie` ikut dikirim di endpoint list.

## Bukti (before, 2026-11-03)
- DB UAT: rata-rata per baris 563 KB (KTP 375 KB, profile_pic 131 KB, selfie 50 KB); tanpa 3 kolom tersebut ±7 KB
- k6 `load` internal: 26,5 req/s, p95 997,6 ms, 92 MB/s data diterima (±3,4 MB per response)
- Allure **TC-26** gagal (kolom gambar ada di response), **TC-27** gagal (561 KB per baris)
- Detail: `docs/load-test/2026-11-03/BASELINE-ISSUES.md` §9.4

## Perlu keputusan
Apakah konsumen API membutuhkan kolom gambar di endpoint list? (breaking change)

## Rencana perbaikan
`docs/implementation-fixing-plan.md` P1: daftar kolom eksplisit tanpa gambar; endpoint detail/flag `include_images` untuk gambar.

## Definisi selesai
- [ ] Keputusan konsumen API tercatat
- [ ] TC-26 & TC-27 lulus, tag `@known_issue` dihapus
- [ ] k6 after fix disimpan di `tests/k6/published/after/` dan dibandingkan
