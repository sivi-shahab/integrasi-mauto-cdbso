## Ringkasan
Query memakai `SELECT *` sehingga `request_base64_ktp`, `profile_pic`, dan `selfie` ikut dikirim di endpoint list.

## Bukti (before, 2026-11-03)
- DB UAT: rata-rata per baris 563 KB (KTP 375 KB, profile_pic 131 KB, selfie 50 KB); tanpa 3 kolom tersebut ±7 KB
- k6 `load` internal: 26,5 req/s, p95 997,6 ms, 92 MB/s data diterima (±3,4 MB per response)
- Allure (definisi awal) **TC-26** gagal (kolom gambar ada di response), **TC-27** gagal (561 KB per baris)
- Detail: `docs/load-test/2026-11-03/BASELINE-ISSUES.md` §9.4

## Keputusan (2026-11-03)
Kontrak response **tetap sama**: kolom gambar tetap dikirim.

## Perbaikan
Serialisasi JSON memakai orjson (`FastJSONResponse`) tanpa `jsonable_encoder`. Output byte-identik.
Detail & bukti before/after: `docs/load-test/2026-11-03/FIX-9.4.md`.

## Definisi selesai
- [x] Keputusan konsumen API tercatat (kontrak tetap)
- [x] TC-26 (guard kontrak) & TC-27 (render < 35 ms) lulus tanpa `@known_issue`
- [x] k6 stress after fix disimpan di `tests/k6/published/after-fix-9.4/` dan dibandingkan
