## Ringkasan
Ukuran pool hard-coded (default SQLAlchemy). Saat service dijalankan multi-worker, total koneksi = worker × (pool_size + max_overflow) dan harus di bawah sisa `max_connections` PostgreSQL.

## Bukti (before, 2026-11-03)
- Allure **TC-23** gagal: `pool_size=5, diharapkan 3 dari env DB_POOL_SIZE (belum bisa dikonfigurasi)`
- PostgreSQL UAT: `max_connections=500`, koneksi aktif saat capture 142
- Detail: `docs/load-test/2026-11-03/BASELINE-ISSUES.md` §9.2

## Rencana perbaikan
`docs/implementation-fixing-plan.md` P2: env `DB_POOL_SIZE`, `DB_MAX_OVERFLOW`, `DB_POOL_TIMEOUT`; multi-worker; koordinasi DBA untuk batas koneksi.

## Definisi selesai
- [ ] TC-23 lulus, tag `@known_issue` dihapus
- [ ] `.env.sample` & README diperbarui
- [ ] Batas koneksi disetujui DBA
